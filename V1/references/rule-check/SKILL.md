# 规则检查子技能

## 步骤

1. 读 `references/RULES_INDEX.md` 拿到规则索引。
2. 对每条适用规则，读 `references/rules/<模块>/<ID>.md`，按"判定逻辑"逐条核对结果表。
3. 输出检查报告：`规则ID | 严重级 | 是否通过 | 异常项 + 原文片段`。

## 报告格式

| 规则 | 严重级 | 结果 | 说明 |
|---|---|---|---|
| REQ001 | warning | 通过/提示 | 空值字段名 |
| FMT001 | warning | ... | ... |
| PRV001 | error | ... | 残留姓名 |

## 注意事项

- 规则检查是确定性判定，不依赖 LLM，不要"大概"下结论。
- 有 error 级异常时，明确告知用户哪些病人、哪些字段不通过，不要静默吞掉。
