# 脱敏子技能

## 敏感词识别提示词（固定，勿改）

```
现有病人的病历数据，请结合上下文提取以下文本中的一切医院名和所有人名(姓名可能重复出现在任何地方，且字符“姓名”之后一定为患者的名字)，并严格按照以下格式返回（不要返回任何额外的信息！！）:
提取的医院名和人名，如果有多个用换行符“\n”间隔，如无，返回null
例如：坪山人民医院\n肇庆市第一人民医院\n张三\n李四\n王五
```

## 步骤

1. 取图转文 Markdown（docx-ocr 产出）。
2. 用固定直连库识别敏感词（内部已自动完成：按 `# 图片 N` 拆 parts、每 15 张一组、正则自动提取床号/号码/手机号/地址、调 llm-mcp 识别医院名/人名、并入手动词）：
   ```bash
   python "<skill 的 mcp_client 目录>/llm_sensitive.py" \
       "<图转文.md>" "<sensitive_words.txt>" [--manual "<手动词文件.txt>"]
   ```
   - `--manual`：手工补齐词文件（每行一个），用于补检测覆盖不到的项——患者姓名（通常来自文件名）、医院名多变体、住院号、OCR 变体（如 `病床号：603741`、`史振鸡`=史振鸿）、多次住院的各床号/流水号等。
   - 脚本调用本地 `qwen3:32b`，`model_type=local`（敏感文本不出本机）。
3. 谱好手动词后，可重跑上一步（多次住院病历尤其需要）：**多次住院病历每个住院号的床号/流水号都不同**，且常以 `数字+床`、`(流水号` 等无标签格式出现，`auto_extract` 抓不到，务必用 `\d{3,6}床`、`\(\d{5,9}` 模式在脱敏文件上扫描补齐后再重跑 mask.py。
4. 调脚本脱敏（脚本会清洗、去重、按长度降序掩码）：
   ```bash
   python references/desensitize/scripts/mask.py <markdown文件> <sensitive_words.txt> <脱敏输出文件> [敏感词清单输出文件]
   ```
5. 输出：脱敏后文本（掩码为等长 `█`）+ 敏感词清单。

## 阶段一产物（到此停下）

阶段一完成后，应输出三个产物并**停下询问用户**是否继续提取：
1. 图转文 Markdown（docx-ocr 产出）
2. 敏感词清单
3. 脱敏后全文

不要自动进入结构化提取，等待用户确认并上传「提取字段 excel」。

## 注意事项

- 掩码由脚本完成，不要自己用 find-replace 手改。
- 若某病人名字没被识别出来（漏识别），把该名字补进 `sensitive_words.txt` 再重跑 mask.py 即可。
